认证方式（API Key）

在控制台"API Key 管理"中创建密钥（可设置过期时间），
调用消息 API 时携带请求头：

  X-Api-Key: <你的 key>

也支持 query 方式：?key=<你的 key>

语义说明

队列只有名字，没有延迟/可见性超时/TTL 等属性。
接收即删除：GET 取到的消息会被立即物理删除，不会再投递（不需要 ack）。
无消息时可长轮询：wait=N 最多挂起 N 秒等新消息。

消息 API

方法路径说明
POST/api/queues创建队列 {"queueName":"q1"}
GET/api/queues队列列表（含累计计数）
GET/api/queues/{name}队列详情
DELETE/api/queues/{name}删除队列
POST/api/queues/{name}/messages发送消息 {"body":"..."}
POST/api/queues/{name}/messages/batch批量发送 {"bodies":["..",".."]}（≤16条）
GET/api/queues/{name}/messages?num=1&wait=5接收消息并删除（wait=长轮询秒数，num=批量数）
GET/api/queues/{name}/messages/peek查看队首消息（不消费）
POST/api/queues/{name}/peek-batch分页查看消息（不消费）{"offset":0,"limit":10}
